# Divan Bula

Каталог мягкой мебели на React + Vite с реальными фото и видео товаров.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверка тестов и production-сборки:

```bash
npm run check
```

## Управление каталогом

Кнопка **«Управление каталогом»** находится внизу сайта. Раздел защищён паролем. В редакторе можно:

- менять название, категорию, цену, старую цену, размеры и описание;
- загружать до 6 фотографий товара;
- создавать и удалять товары;
- экспортировать и импортировать резервную копию каталога в JSON.

Загруженные изображения автоматически уменьшаются, конвертируются в WebP и сохраняются в Vercel Blob. На опубликованном сайте товары, цены и фотографии хранятся в общем облачном каталоге и доступны всем устройствам. При первом сохранении редактор предложит опубликовать найденные локальные изменения.

Для локальной разработки задайте пароль в `.env.local`:

```env
VITE_ADMIN_DEV_PASSWORD=ваш-локальный-пароль
```

Локальная авторизация сохраняется только до закрытия вкладки.

## Публикация на Vercel

Проект готов к статической публикации. При импорте Git-репозитория Vercel определит Vite автоматически:

- Build command: `npm run build`
- Output directory: `dist`
- Environment variables: `ADMIN_PASSWORD` и `ADMIN_SESSION_SECRET`

Также можно опубликовать из терминала после авторизации в Vercel:

```bash
npx vercel
```

В настройках проекта Vercel добавьте:

- `ADMIN_PASSWORD` — пароль владельца;
- `ADMIN_SESSION_SECRET` — случайная строка длиной не менее 32 символов.

Также подключите к проекту публичное Vercel Blob-хранилище. Новые подключения используют автоматически настроенную OIDC-авторизацию (`BLOB_STORE_ID`), а старые могут использовать `BLOB_READ_WRITE_TOKEN`.

Пароль проверяется серверной функцией и не попадает в клиентский JavaScript. После входа создаётся защищённая HttpOnly-сессия на 8 часов. Файл `vercel.json` уже содержит SPA rewrite, поэтому прямые переходы по адресу сайта будут работать корректно.
