# DIVAN BULA --- Design Concepts & AI Prompts

## Общие правила бренда

**Бренд:** Divan Bula\
**Тип компании:** мебельная компания\
**Основная продукция:** диваны, кровати, столы, шкафы, кресла и мебель
для дома/офиса.

### Логотип

Использовать предоставленный логотип Divan Bula как основной брендовый
знак. Не изменять пропорции и не перерисовывать логотип.

### Общие требования ко всем вариантам

-   Современный responsive website.
-   Desktop-first дизайн с полноценной мобильной адаптацией.
-   Язык интерфейса: русский.
-   Использовать реальные качественные фотографии мебели и интерьеров.
-   Не перегружать интерфейс декоративными элементами.
-   Основной CTA: **«Перейти в каталог»** / **«Выбрать мебель»**.
-   Дополнительный CTA: **«Получить консультацию»**.
-   Навигация: Главная, Каталог, О компании, Проекты, Отзывы, Контакты.
-   Добавить телефон и кнопку связи.
-   Все карточки товаров должны иметь единый визуальный стиль.
-   Изображения мебели должны выглядеть реалистично и премиально.
-   Не использовать изображения людей в качестве главного визуального
    элемента.
-   Не использовать градиенты, если они отдельно не указаны в концепции.
-   Типографика должна быть читаемой и современной.

# Вариант 01 --- Светлая премиальная классика

## Концепция

Тёплый, дорогой и спокойный сайт. Основная задача --- вызвать доверие и
показать Divan Bula как качественного производителя мебели.

**Ключевые слова:** premium, warm, elegant, minimal, comfort, trust.

## Цветовые компоненты

  Компонент         HEX
  ----------------- -----------
  Основной фон      `#F7F4EE`
  Вторичный фон     `#EEE9DF`
  Белый             `#FFFFFF`
  Основной текст    `#242321`
  Вторичный текст   `#6E6A62`
  Золотой акцент    `#B58A3A`
  Светлый золотой   `#D6B46A`
  Граница           `#DDD7CC`
  Тёмная секция     `#242522`

### UI

-   Border radius: 8--12px.
-   Кнопки: золотой фон + тёмный текст.
-   Карточки: белый фон, тонкая граница, мягкая тень.
-   Большие фотографии интерьеров.
-   Много свободного пространства.
-   Заголовки можно выполнять элегантным serif-шрифтом.
-   Основной текст --- современный sans-serif.

## Структура

1.  Header
2.  Hero
3.  Преимущества
4.  Категории мебели
5.  Популярные товары
6.  Имиджевый баннер
7.  Наши проекты
8.  Отзывы
9.  CTA
10. Footer

## Prompt для AI-дизайнера

``` text

Use the provided Divan Bula logo exactly as the brand identity.

warm premium minimalism, elegant furniture showroom, sophisticated but approachable, high-end interior design.

#F7F4EE warm ivory background,
#EEE9DF secondary beige,
#FFFFFF white,
#242321 dark charcoal text,
#6E6A62 secondary text,
#B58A3A muted gold accent,
#D6B46A light gold,
#DDD7CC borders.

Create a full responsive website in Russian.

Header:
Divan Bula logo, navigation "Главная", "Каталог", "О компании", "Проекты", "Отзывы", "Контакты", phone number and a premium outlined CTA.

Hero:
large cinematic photograph of an elegant modern living room with a premium sofa.
Headline:
"Качественная мебель для вашего комфорта"
Subheadline:
"Стильные, удобные и долговечные решения для дома и офиса."
Primary CTA:
"Перейти в каталог"

Add:
- four trust indicators
- furniture categories
- premium product cards
- editorial interior banner
- project gallery
- customer reviews
- consultation CTA
- detailed footer.

Use generous whitespace, elegant typography, subtle borders, refined gold accents, realistic furniture photography and premium editorial composition.

Avoid excessive gradients, excessive shadows, cartoon graphics, cheap-looking ecommerce UI and visual clutter.
```

для разработки:

2. типографику;

4. UI-компоненты;

Не придумывай другую дизайн-систему.
